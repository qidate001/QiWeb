游戏总览

版本: 1.0

问身·问己·问心，是一款集生存、数值平衡与概率博弈于一体的文字探索游戏。

核心目标：在这座世界里坚持生活 100 天。每天只能干两件事，且需要时刻关注你的理智、心情、饥饿与口渴。

⚠️ 注意事项：
  • 饥饿值与口渴值大于100或小于等于0即死。
  • 理智低于0即死，心情低于10会开始扣除理智，心情大于等于200即死。
  • 污染值达到100即死；健康值为0即死。
  • 各项数值每天都会自动衰减。

生存数值

💰 金币

日常消耗必需品。可由工作获取，二阶段后每日会受（天数-10）*2的税金影响。

🧠 理智

低于0即死。可通过知识区恢复。关键数值，影响部分特殊剧情的触发。

😊 心情

低于0扣理智，高于200即死。可通过外出游玩恢复。

🍔 饥饿/口渴

基础上限100，每天递减15。超出上限或低于0都会导致死亡。可通过“美食街”补充。

💪 健康/污染

健康值受极端天气影响，二阶段后每日衰减。污染值达到100即死。

🍀 气运

影响每日随机事件是好是坏。点击左侧滑块，查看气运值对事件的概率影响。

日常行动

💼 去挣钱 解锁

基础收益：30-70G，消耗心情。

打零工 (初) ➔ 跑外卖 (经验15) ➔ 做代购 (经验40) ➔ 去上班 (经验80) ➔ 做开发 (经验120)

🍜 美食街

补充饥饿值和口渴值（有饺子、肉夹馍、冰淇淋等）。高价格的高品质食物（如餐餐盛宴）可大量恢复。

📚 知识区

恢复理智，是生存的关键。

🎡 出去玩

稳定恢复心情值。

⛰️ 去冒险

主线剧情触发点，可能遭遇极端天气、污染事件或故事线。
